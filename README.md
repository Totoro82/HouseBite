# HouseBite

> A web app that turns your household into a shared smart pantry — helping you waste less, spend less, and keep track of what you already have.

HouseBite gives households a shared space to manage food more effectively. Create a household or join an existing one, add products with expiry dates, see what is about to expire, and get recipe suggestions based on what you already have at home.

Beyond the pantry, HouseBite helps you stay on top of grocery spending with a shared monthly budget, lets members scan receipts to log grocery purchases automatically, and supports individual dietary restrictions so meal planning works for everyone.

---

## Why it matters

- **53%** of food waste in the EU comes from households
- **69 kg** of food waste per person is generated by EU households each year

*Source: European Commission, based on Eurostat 2025.*

---

## Features

| Feature | Description |
|---|---|
| **Expiry tracking & recipe suggestions** | Keep track of what is about to expire and discover recipe ideas that use it, adapted to everyone's dietary needs |
| **Shared shopping list** | Grocery list for the whole household, synced in real time |
| **Receipt scanning** | Snap a photo of your receipt, filter it, and keep track of receipt history |
| **Budget tracking** | Set a monthly budget and follow your household spending as receipts come in |
| **Household management** | Create a household, assign admin roles, and personalize each home with user-chosen avatars |
| **Dietary restrictions** | Manage diets and allergies per member so recipe suggestions work for everyone |

## Tech stack

**Frontend**
- React 19 + TypeScript + Vite
- Mantine UI + Tabler Icons
- React Router
- PWA manifest (installable on phones and desktops)

**Backend & data**
- Supabase Auth
- PostgreSQL with Row Level Security
- Supabase Edge Functions (Deno)

**Integrations**
- Spoonacular — recipe search
- OpenAI — receipt scanning

**Workflow**
- Scrum methodology with sprint-based delivery
- Git version control
- Docker for local dev

---

## Architecture

```
Presentation  (pages/, components/)
      ↓
Application   (api/, lib/)
      ↓
Domain        (entities: Household, Receipt, Member)
      ↑
Infrastructure (Supabase, PostgreSQL, Auth)
```

Data isolation is enforced at the database level via Row Level Security. Every query from the frontend goes through RLS — there is no privileged backend layer except Edge Functions using the service role key.

## Development

### Prerequisites

- [Node.js LTS](https://nodejs.org/en/download)
- [Deno](https://deno.com/)

### Frontend

```bash
cd web
npm install
npm run dev        # start local dev server with HMR
npm run build      # type-check + production bundle
npm run lint       # ESLint
npm run preview    # preview production build locally
```

### Edge Functions

```bash
npx supabase functions new <function-name>
npx supabase functions deploy <function-name> --project-ref ikemmjauwrahrrlgewta
```

### Environment variables

Create `web/.env`:

```
VITE_SUPABASE_URL=https://ikemmjauwrahrrlgewta.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=...
```
